# H-Bridge DRV8833

<img width="582" height="416" alt="SchemaDRV8833" src="https://github.com/user-attachments/assets/f242faf8-f29a-47be-abea-4e20e36065cd" />

De DRV 8833 wordt zo aangesloten dat de DC motoren voor en achtruit kunnen draaien (ideal voor scherpe bochten), de H-brug wordt gevoed door de batterijspanning (GND,VCC) en de ingangen 1-4 worden met de PWM pinnen van de arduino verbonden. Zo kan met behulp van een analogWrite de snelheid van de motoren bepaald worden. De motoren worden met uitgangen 1-4 verbonden.
